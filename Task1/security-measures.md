## Аворизация и ролевой доступ
1. На файловом сервере настраиваются группы пользователей: Ресепшн, Врач, бэк-офис. Для каждой из групп настраивается доступ в соответствующие папки с файлами:
    - Ресепшн - папка с договорами и сканами личных документов
    - Врач - папка с мед. картами и снимками
    - бэк-офис - папка с платежными ведомостями и другими документами
1. На компьютерах врачей и сотрудников ресепшн настраивается screensaver, срабатывающий при 30с неактивности пользователя
1. Передача данных между компьютерами пользователей и сервером шифруется через SSL/TLS

## Оформление договора
```mermaid
graph LR
    Customer(Пациент) 
    Employe(Сотрудник ресепшн)
    DB[(Зашифрованное файловое хранилище)]
    Customer --> |ФИО, Дата рождения, телефон, email, Адрес, место работы/учебы, хронические заболевания| Employe
    Employe --> |ФИО, Дата рождения, телефон, email, Адрес, место работы/учебы, хронические заболевания <b>TCP SSL/TLS</b>| DB
    Employe --> |Создание медицинской карты с именем и отчеством, хроническими заболеваниями <b>TCP SSL/TLS</b>| DB
    Employe --> |Договор| Customer
    Employe --> |Договор <b>TCP SSL/TLS</b>| DB
```

```mermaid
    Employe --> |Сохранение записи <b>TCP SSL/TLS</b>| DB
```

## Прием в клинике
```mermaid
graph LR
    Customer(Пациент)
    Employe(Врач)
    Employe1(Сотрудник ресепшн)
    DB[(Зашифрованное файловое хранилище)]

    Employe --> |Назначения, рекомендации| Customer
    Employe --> |Результаты осмотра, назначения <b>TCP SSL/TLS</b>| DB 
    Employe --> |Счет для оплаты <b>TCP SSL/TLS</b>| DB
    DB --> |Медицинская карта с именем и отчеством, без дополнительной информации <b>TCP SSL/TLS</b>| Employe
    DB --> |Счет для оплаты <b>TCP SSL/TLS</b>| Employe1
    Employe1 --> |Счет для оплаты| Customer
    
```

## Оплата приема
```mermaid
graph LR
    classDef highlight fill:#BC008D,stroke:#000,color:#FFF

    Customer(Пациент)
    Employe(Кассир)
    System[Кассовый аппарат]
    System1[1C Бухгалтерия и предприятие]

    Customer --> |Счет| Employe
    Employe --> |Номер счета, сумма| System:::highlight
    System:::highlight --> |Номер счета, оплаченная сумма <b>TCP SSL/TLS</b>| System1:::highlight
```

## Работа с ТМЦ

```mermaid
graph LR
    
    Employe(Сотрудник склада)

    System:::highlight --> |Данные о списании ТМЦ <b>TCP SSL/TLS</b>| System1:::highlight
```
